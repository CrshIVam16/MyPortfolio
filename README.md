# 👩🏻‍💻 Portfolio

A personal portfolio website built with React, Vite, Tailwind CSS, and React Icons.

## Overview

This project showcases a developer portfolio with sections for projects, skills, and contact details. It is structured as a modern React application using Vite for fast development and optimized builds.

## Features

- React + Vite-based frontend
- Tailwind CSS styling
- Responsive layout
- Project cards and skill sections
- Easy local development and build scripts

## Getting Started

Install dependencies:

```bash
npm install
```

Run the development server:

```bash
npm run dev
```

Build for production:

```bash
npm run build
```

## Project Structure

- `index.html` — application entry template
- `src/main.jsx` — React application bootstrap
- `src/App.jsx` — top-level app component
- `src/assets/` — static assets and images
- `src/components/` — reusable UI components
- `src/data/` — project and skills data files
- `public/` — static public files

## Notes

This repository is intended for portfolio presentation and can be extended with additional projects, contact methods, or custom animations.
